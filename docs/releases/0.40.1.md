# 0.40.1

## List availability

- The default corpus ceiling was raised above the shipped catalog's working
  size. If a later corpus exceeds its limit, status, API, and metrics report
  the frozen state instead of silently presenting it as healthy.
- A source that exceeds its own limit retains its last accepted data rather
  than disappearing from the active corpus.

## Upgrade verification

- The installer waits longer for a DNS listener while a large corpus loads,
  reports that startup is still in progress, and stops early if the service
  process exits.
- DNS verification now distinguishes a failed `dig` command from a successful
  non-empty answer.

## Configuration recovery

- Migration backups are visible to `warden config restore --list` and can be
  read by the restore path.
- An unreadable backup is reported as an error rather than as an absent file.
